# 虚室 Xushi

把一个片刻，留在纸上。写下文字，按一次快门，相纸自动推出、覆盖纸揭开；可以跳过动作、保存 PNG、回看或删除。

## 网站

https://tunqigua.github.io/xushi/

## 数据与保存

文字只保存在当前浏览器，不上传，不写入网址。草稿按标签页保存，正式片段保存在浏览器本地；清理浏览器数据可能丢失内容。请独立保存需要保留的 PNG。下载发起不代表设备已经保存，请在下载目录或相册中核对。

PNG 只有完整原文、底色、暖白边框和纸张纹理，不含日期、感受、按钮或动画层。日期与感受在纸外，感受可不选。当前正文上限为 120 个可感知字符，超限保留输入并提示调整。

## 运行和发布

原生 HTML、CSS、JavaScript ES Modules，无需安装依赖或后端。使用静态 HTTP 服务预览；GitHub Pages 从 main 分支根目录发布。`.nojekyll` 保持静态资源原样提供。

本仓库仅包含发布文件。完整设计案例、实施快照、参考视频、测试中间文件和本地启动工具保留在作者本机，未上传。

## 验证边界

已有隔离 Chromium 的桌面/手机视口、导出和错误恢复等模拟检查。视口模拟不代表 iOS/Android 真机；Safari/Firefox、系统输入法/软键盘、真实相册落盘及读屏未验收。极长图的内存与解码能力因设备而异。不宣称人的情绪改善或全设备兼容。

## 分工

设计者提供方向、参考和约束，负责视觉与叙事取舍；AI 在授权范围内实现、修正并整理实际模拟检查证据。独立手势试作没有取代默认自动出片，未纳入本次公开入口。
